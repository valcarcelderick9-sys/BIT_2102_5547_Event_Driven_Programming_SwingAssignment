# Java Swing Assignment

## Overview
This project is a basic interactive Graphical User Interface (GUI) created with Java Swing for an Event-Driven Programming assignment.

The application demonstrates a main window, a panel, a welcome label, an application icon, and buttons that respond to user actions.

## Features
- Displays a welcome message.
- Includes a **Change Text** button to update the welcome message.
- Includes buttons to change the panel background colour:
  - Blue Background
  - Green Background
  - Yellow Background
- Demonstrates Java Swing components such as `JFrame`, `JPanel`, `JLabel`, and `JButton`.
- Demonstrates a constructor, inheritance, and event listeners.
- Includes a wireframe designed for the application.

## Requirements
- Java Development Kit (JDK) compatible with the source code.
- An IDE such as IntelliJ IDEA or Visual Studio Code (optional).
- `app-icon.png` for the custom application icon, if used by the source code.

## How to Run
1. Download the repository to your computer.
2. Open the project in your Java IDE.
3. Ensure `SwingAssignment.java` is in the `src` folder and the class name matches the filename.
4. Make sure the icon file is in the location expected by the code. If the icon is missing, the application may run without a custom icon.
5. Run the `SwingAssignment` class.

If the project does not include an IDE project configuration, create/open a Java project and add `SwingAssignment.java` to its source folder.
